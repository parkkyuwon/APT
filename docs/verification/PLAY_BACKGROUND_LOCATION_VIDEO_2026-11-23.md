# Google Play 백그라운드 위치 권한 제출 영상

## 현재 상태

사용자가 Android 휴대폰을 USB로 연결해 실제 앱 화면을 촬영하기로 했다. Android 17/API37 휴대폰 연결을 확인했으며 제출용 영상은 아직 생성하지 않았다. 설치된 앱 제거·데이터 초기화·위치/USB 권한의 대리 승인은 하지 않는다. 배포는 사용자 지시대로 API/CLI를 사용하며, 이 문서는 Play Console UI 자동화 권한을 추가하지 않는다.

확인한 설치본은 Play 설치 `1.1.5 (22)`다. 설치본 서명 식별자와 로컬 업로드 키의 식별자가 달라 로컬 APK 덮어쓰기를 시도하지 않았다. 기기에서 기존 APK를 읽는 작업도 연결 재인증/전송 실패로 완료되지 않아 전체 설치 인증서 SHA256은 아직 확보하지 못했다. 사용자 휴대폰에서 화면 녹화·앱 제거·권한 초기화·운영 자료 변경은 수행하지 않았다.

기존 23번 AAB의 사용 여부는 사용자가 알지 못한다고 답했다. 해당 번들에서는 기존 화면 표식은 발견되지만 추가 사전 안내 표식이 없어 최신 소스로 24번을 새로 빌드했다. 최종 `AppBundle/releases/2026-11-23-v1.1.6-24/apt-ev-service-v1.1.6-24.aab`는 패키지/버전·기존 업로드 인증서 일치·12개 ELF64 라이브러리 16KB 정렬·필수/금지 권한 검사와 모든 ABI의 사전 안내 표식 검사를 통과했다. SHA256: `31c1b80a2dee145b049c3975b61cf34f1817aa874148013172b8b739a53521fd`. 이는 휴대폰 설치·실행 검증을 의미하지 않는다.

다음 전제는 Play API 인증 설정과 Play 서명 최신 설치본 확보다. 현재 프로젝트에 Play 서비스 계정 JSON이 없고 관련 로컬 설정·다운로드 파일에서도 적절한 기존 키를 찾지 못했다. 공식 `generatedapks.list/download` API의 서명 APK 확보 경로는 확인했고 명시적으로 제공된 자격 증명만 사용하는 보조 도구를 준비했다. API를 사용할 수 있게 된 뒤 실제 서명과 호환성을 확인하고 설치본을 업데이트해야 한다. 인증/서명 검사를 우회하거나 기존 앱을 삭제해 해결하지 않는다.

## 영상에 필요한 실제 장면

공식 요구사항: https://support.google.com/googleplay/android-developer/answer/9799150?hl=ko

1. 앱에서 기능을 찾아 켜는 과정.
2. 앱이 닫혀 있거나 사용 중이 아닐 때도 위치를 사용하는 이유를 설명하는 앱 내 공개 대화상자.
3. 그 대화상자 다음에 나타나는 Android 위치 권한 요청 및 필요한 OS 설정 과정.
4. 앱이 화면에 없는 상태에서 해당 기능이 실제로 동작하는 장면.

Android 화면이어야 하며, 권장 길이는 30초 이하이다. 기능의 실제 대기가 더 길면 원본을 충분히 녹화한 뒤 대기 구간만 줄이고 화면에 시간 경과를 표시한다. 합성된 권한창이나 가짜 알림을 실제 동작처럼 제출하지 않는다.

## 촬영 전 확인

- USB 디버깅과 PC 연결 승인은 휴대폰 소유자가 직접 수행한다.
- Android 버전·설치 버전·서명을 확인한다. Play에서 설치한 앱과 로컬 APK 서명이 다르면 설치를 강제하거나 기존 앱을 삭제하지 않는다.
- 촬영할 설치본에 백그라운드 위치 사용 사전 안내가 실제로 포함되어 있어야 한다. 단순히 소스 파일에 문구가 있다는 사실을 설치본 확인으로 대체하지 않는다.
- 운영 계정의 회원/주차 데이터를 시연용으로 변경하지 않는다. 등록된 실제 신호 지도와 관리자의 공용 사용 설정 상태를 먼저 확인한다. 없는 기능이나 미활성 기능을 편집으로 동작한 것처럼 보이게 하지 않는다.
- 앱 이용에 필요한 로그인·위치/알림 권한 선택은 사용자와 함께 진행한다. 기존 권한을 초기화해야 재촬영할 수 있는 경우 먼저 그 영향을 설명한다.
- 개인 주소, 계정 이메일, 차량번호 등 제출에 불필요한 정보가 노출되지 않도록 시험 장소를 고르거나 해당 부분을 가린다.

## 권장 구성

| 장면 | 내용 |
|---|---|
| 시작 | AptEvService → 더보기 → 집 주변 지하 위치 안내 |
| 설정 | 개인 반경 설정을 확인하고 감시 켜기 선택 |
| 사전 안내 | 앱이 닫혀 있을 때의 위치 사용 목적과 기기 저장/공유 범위를 읽을 수 있게 표시 |
| 권한 | 계속 → Android 위치 권한 요청 → 필요한 백그라운드 위치/알림 허용 |
| 백그라운드 | 홈 화면으로 나간 뒤 실제 주변 진입/위치 품질 저하에 의한 안내 알림 표시 |
| 결과 | 안내 알림을 선택해 앱의 지하 지도로 돌아옴 |

현재 구현은 유효한 반경 내부 근거와 실제 위치 관찰을 요구한다. 서비스 시작 이후 정상 위치가 없다고 판단하는 구간과 지속된 품질 저하 구간이 있으므로 홈 화면 전환 직후 알림이 뜬다고 가정하지 않는다. GPS 기능 자체를 끄면 `위치 서비스 OFF`로 관찰이 중지되므로 지하 진입 시연을 대신하지 못한다.

## 제출

실제 영상을 확인한 뒤 Google이 열 수 있는 YouTube 또는 Google Drive 영상 링크를 제출한다. 서비스 계정 API 권한이나 배포 API 사용은 백그라운드 위치 권한 심사를 대신하지 않는다. 이 문서는 영상·URL·심사 승인이 생성되었다는 증거가 아니다.
