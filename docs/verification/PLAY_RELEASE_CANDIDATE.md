## Console 후속 작업

사용자는 브라우저 연결 후 배포 진행을 선택했다. 현재 연결된 브라우저 목록은 비어 있고 Windows 화면 제어 연결도 사용할 수 없다. 따라서 AAB 업로드, 스토어 아이콘 등록, 심사 제출 및 프로덕션 게시는 수행하지 않았다.

로그인된 Play Console 탭이 연결되면 기존 최고 versionCode, 업로드 인증서, 출시 트랙 및 정책 상태부터 확인한다. 15가 이미 사용되었다면 더 높은 번호로 재빌드하고 검증 기록을 갱신한다. 내부 테스트 등록 후 Android 16 실행 검증과 Console 검사 결과를 확인하고 프로덕션 출시로 진행한다. 로컬 빌드와 서명 검증만으로 Play 등록 가능 여부나 API 정책 해소를 확정할 수 없다.
