# Play 데이터 보안 저장·검토 요청 기록 — 2026-10-21

Play Console에서 아래 내용을 저장한 뒤 21 전체 출시와 함께 검토 전송했다. 이후 활성 구버전 14의 사진 권한 차단을 해결하기 위해 공개 테스트·Alpha도 21로 교체해 프로덕션 21·공개 21·Alpha 21·데이터 보안, 총 4개를 재전송했다. 실제 최종 관찰에서 사전 빠른 검사 표시가 사라지고 **‘변경사항을 검토 중입니다. 앱을 검토하는 과정에서 추가 문제가 발견될 수도 있습니다.’**로 전환돼 Google 심사 단계 진입을 확인했다. Google 승인·실제 게시는 미완료이며 관리형 게시가 켜져 있다.

## 저장한 내용

- 계정 생성·인증은 Google OAuth만 사용한다. 비밀번호 방식은 선택하지 않았다.
- 전송 암호화(HTTPS)를 사용한다.
- 계정 삭제 URL: <https://apt-ev-charging.vercel.app/account-deletion.html>.
- 계정 삭제 없이 일부 데이터만 삭제하는 별도 요청 옵션은 ‘아니요’를 유지했다.
- 아래 항목은 모두 **수집함 / 공유하지 않음**으로 저장했다. 사용자 주도 제공·서비스 제공자 처리에 관한 Console 정의를 적용한 분류이며, 데이터가 기기 밖으로 전송되지 않는다는 뜻은 아니다.

| 데이터 유형 | 처리·필수 여부 | 목적 |
| --- | --- | --- |
| 이름(닉네임 포함), 이메일, 사용자 ID, 기타 개인정보(차량번호) | 지속 처리, 필수 | 앱 기능, 계정 관리 |
| 전화번호(활성 구버전 호환 범위) | 지속 처리, 필수 | 앱 기능, 계정 관리 |
| 사진(번호판 검토·선택 신고 사진) | 필수 | 앱 기능, 계정 관리 |
| 앱 내 메시지, 기타 사용자 생성 콘텐츠 | 선택 | 앱 기능 |
| 앱 상호작용 | 필수 | 앱 기능, 분석 |
| 진단, 기타 앱 성능 데이터 | 필수 | 분석 |
| 기기 또는 기타 ID | 지속 처리, 필수 | 앱 기능, 분석 |

오디오·동영상·위치·연락처 항목은 선택하지 않았으며 광고 목적으로 신고한 항목은 없다. 선택 음성통화는 TURN 미설정으로 비활성 상태다. 실제 기능을 활성화하기 전에는 오디오·연결정보와 TURN 처리자·지역을 다시 검토해야 한다.

## 구버전 및 SDK 범위

새 21 소스는 전화번호 입력·전송을 제거했다. 다만 활성 14/19까지 포함하는 신고 범위를 고려해 기존 전화번호 분류를 유지했다. Git HEAD의 versionCode 14는 `ProfileApi.updateProfile`의 `phoneNumber`와 주차 `contact`를 전송한다. 신규 서버는 이를 무시·제거하지만, 활성 구버전 전송과 기존 서버 저장 경로를 배제한 신고로 바꾸지 않았다. 이 항목은 새 21의 전화번호 수집을 추가했다는 의미가 아니다.

FCM 알림은 선택 기능이지만, 포함된 ML Kit SDK의 진단·성능·기기 식별자 처리에는 앱 내 별도 수신 거부 옵션이 없어 SDK 처리도 포함했다. 이름은 Google 이름과 저장되는 닉네임을 포함하므로 일시 처리로 신고하지 않았다.

근거는 [ML Kit Android 데이터 공개 안내](https://developers.google.com/ml-kit/android-data-disclosure)와 [Google Play 데이터 보안 작성 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)다. 후자는 배포 중인 모든 활성 버전과 포함 SDK를 신고 범위에 포함하도록 안내한다.
