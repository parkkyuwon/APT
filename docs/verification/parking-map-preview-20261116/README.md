# 주차장 도면 단순화 미리보기

이 폴더는 기존 B1/B2 도면과 단순화 이미지를 비교하기 위한 자료다. 2026-11-16 사용자 후속 지시로 단순화 이미지를 `assets/images/B1-simplified.png`, `B2-simplified.png`에 복사해 회원 지도와 관리자 편집기에 적용했다. 원본 `assets/images/B1.png`, `B2.png`는 보존한다.

## 표현 방향

- 유지: 주차 블록, 개별 주차면 구분, 블록 사이 통로, 주요 건물 코어와 계단 위치, 경사로, 기존 청록색·빨간색 사각형과 노란색 원의 상대 위치.
- 생략: 작은 설비, 세부 CAD 해칭, 판독하기 어려운 주석, 표, 인출선, 검은 원형 점.
- 스타일: 흰 배경, 옅은 회색 주차 블록, 읽기 쉬운 외곽선, 구분 가능한 코어와 경사로.

## 검토 범위와 한계

원본 이미지를 참조해 내장 ImageGen으로 만든 시각적 개념 시안이다. 도면의 측량 자료나 정확한 벡터 추적 결과가 아니며, 주차면 개수·벽체·연결부·마커 위치가 달라질 수 있다. 실사용 전 원본과 대조하여 보정해야 한다.

앱은 도면 위에 별도의 백분율 좌표로 마커를 표시한다. 이 시안을 그대로 교체하면 좌표가 맞지 않을 수 있으므로, 적용 전에 원본 크기와 종횡비, 기준점, 모든 마커 위치와 터치 영역을 확인해야 한다. 시안의 색상 도형을 실제 충전 상태 데이터로 해석하지 않는다.

시안 생성 당시에는 앱을 변경하지 않았다. 후속 적용에서 앱 자산 참조를 변경했으며 관련 Flutter 분석·테스트 결과는 `docs/verification/SIMPLIFIED_PARKING_MAPS_2026-11-16.md`에 기록한다.

## 생성 방법

내장 `image_gen` 도구를 사용하며, B1과 B2 각각의 원본을 편집 대상으로 전달했다. CLI나 별도 API 키는 사용하지 않았다. 정확한 생성 지시는 `generation-prompt.txt`에 보관한다.

## 결과와 확인

`compare.html`을 열면 원본과 시안을 나란히 볼 수 있다. `metadata.json`에는 원본·시안의 크기, 종횡비, SHA-256과 좌표 미검증 상태를 기록했다.

| 층 | 원본 | 단순화 시안 |
| --- | --- | --- |
| B1 | 2047 × 1877 | 1310 × 1201 |
| B2 | 3920 × 2240 | 1660 × 948 |

두 시안을 육안 검토했다. 주요 주차 블록과 통로, 경사로의 상대 배치가 드러나고, 기존 색상 도형은 B1에서 청록 사각형 2개·빨간 사각형 1개·노란 원 2개, B2에서 청록 사각형 9개·빨간 사각형 2개·노란 원 12개가 보인다. 임의 동 번호나 방향 화살표를 추가하지 않았다.

코어 내부의 계단 모양은 식별을 위한 도식이며 정확한 계단실 구조를 재현한 것이 아니다. 주차면 개수와 세부 경계는 검증하지 않았다. 종횡비도 픽셀 반올림 때문에 원본과 미세하게 다르다. 앱에서는 기존 지도 영역 비율로 표시하며, 적용 후에도 실제 위치 정확도를 확인하려면 원본을 기준으로 한 정밀 추적·현장 좌표 대조가 필요하다.

`git diff --numstat -- assets/images/B1.png assets/images/B2.png` 출력이 비어 있어 원본에 Git 변경이 없음을 확인했다. 비교 HTML의 로컬 이미지 참조 대상 4개가 모두 존재하는지도 확인했다.
