# 집 반경 지도·권한 안내 검증

## 변경 범위

사용자가 OpenStreetMap 방식을 선택했다. HomeAreaMap은 온라인 도로 지도에 위치 마커와 실제 미터 반경 원을 표시하며 좌표/반경 변경에 맞게 카메라를 조정한다. 현재 위치, 수동 좌표, 지도 터치를 지원한다. 지도 출처 링크, 앱 User-Agent, HTTP 캐시, 타일 실패 시 재시도를 포함한다. 화면 밖 일괄 다운로드는 하지 않는다. 집 좌표의 기기 계정별 보안 저장과 공용 비콘/B1·B2 자료 계약은 유지한다.

감시 켜기에서 백그라운드 위치 사용 사전 안내 후 OS 권한 요청을 진행한다. 정확한 위치, 기기 위치 서비스, 백그라운드 위치, 알림의 부족 조건은 별도 팝업에서 설정으로 이동한다. Android 앱 위치/백그라운드는 앱 상세 설정에서 권한 → 위치로 이동한다. 알림은 앱 알림 설정, 위치 서비스는 휴대폰 위치 설정을 연다. 설정 복귀 후 실제 상태를 확인하고 사용자 시작 활성화만 이어간다. 취소나 관리자 중지에는 활성화하지 않는다.

## 자동 검증

- 변경 전 새 지도/팝업 기대가 실패하는 것을 확인: build/home-area-red-ascii.log.
- Flutter targeted 14개 통과: build/home-area-green.log.
- Flutter 전체 292개 통과: build/home-area-full-test.log.
- flutter analyze --no-fatal-infos 문제 없음: build/home-area-analyze.log.
- 테스트 실행은 비 ASCII 임시 경로에서 엔진 isolate 생성이 실패하여 TEMP/TMP=D:/Temp로 실행했다. 앱 기능의 실패와 구분한다.
- 기존 24번 산출물은 보존하며 새 산출물은 1.1.7+25로 생성한다.

## 게시와 현장 검증 범위

별도 서버 D:/vsCodeProg/APT-Prj/privacy.html에 OpenStreetMap 지도 요청/기기 캐시 설명 1.5를 준비했다. 이 변경의 서버 게시나 Play 업로드는 이 기록만으로 완료로 보지 않는다. 이번 변경으로 공용 비콘 데이터를 생성하거나 운영 관리자의 사용 설정을 바꾸지 않았다.

Android 서명 빌드, 휴대폰 업데이트, 지도 실제 로딩과 OS 설정 복귀 확인은 아래 실기기/산출물 기록에 사실대로 추가한다. 실제 지하 진입·GPS 품질 저하·자동 알림과 내 위치 추정 정확도는 현장 검증이 별도로 필요하다.

## 산출물·실기기 후속 확인

- `AppBundle/releases/2026-11-23-v1.1.7-25/apt-ev-service-v1.1.7-25.aab` 서명 빌드 성공. SHA256 `a1aa791aaed5465dab5914603aa371f82d7b65d1758c9a626060ca136d11d328`.
- 동일 업로드 인증서, package apt.ev.service, versionCode25/name1.1.7, minSdk24/target36, 선택 하드웨어, 12개 ELF64 라이브러리 16KB 정렬과 모든 libapp.so의 지도/권한 팝업 표식을 검증했다. `aab-verification.json`과 `native-alignment.json` 참조.
- bundletool로 동일 서명 universal APK를 생성하고 Android17 실기기의 로컬 서명24 위에 `adb install -r --no-streaming` 업데이트 성공. 삭제·데이터 초기화 없이 설치25와 실제 앱 기동을 확인했다.
- 실제 온라인 OSM 타일, 지도 선택 시 마커와 200m 원, 앱 권한 설정 화면 열기 및 앱 복귀를 확인했다. 첫 시각 검증의 서울 중심 임시 선택은 저장하지 않고 화면을 나왔다.
- 읽기 전용 독립 코드 검토에서 차단 문제 없음. 권한 팝업별 설정 복귀/취소/관리자 중지 동작은 자동 테스트로 검증했으며 모든 OS 권한 선택을 대신 조작하지 않았다.
- 사용자가 별도로 현재 휴대폰 위치를 집 중심으로 사용하도록 답하여, 촬영 과정에서 유효한 현재 위치로 개인 반경200m를 실제 저장했다. 좌표 값은 문서에 기록하지 않는다. 감시는 중지 상태다.
- 앱에는 관리자 사용 설정·신호 지도 배포가 필요하다는 상태가 표시됐다. 사용자가 지하 현장 이동이 어렵다고 답하여 이번에는 설정 시연 영상만 제작한다. 실제 알림/지하 추정 동작을 영상으로 합성하거나 운영 비콘 자료를 만들지 않았다.

## 설정 시연 영상

원본 실기기 촬영은 `build/video-setup-25/raw-setup.mp4`에 보관한다. 개인 위치가 포함되므로 공개할 파일로 사용하지 않는다. 편집본 `D:/vsCodeProg/apt-location-setup-25.mp4`만 전달한다. 지도 상세·위경도·상태 표시줄을 가리고 실제 UI 위의 마커/반경 색상은 원본 픽셀로 유지한다. YouTube 제목/설명 예시는 인접 `apt-location-setup-25-youtube.txt`다.

이 영상은 사전 안내·항상 허용 변경 완료·실제 백그라운드 알림을 증명하는 최종 Play 심사 영상이 아니다. 관리자 실제 측정·배포 및 현장 이동이 가능할 때 해당 장면을 추가해야 한다.

최종 편집본은 36.5초, 1080×2340, 30fps, H.264 MP4, 무음, 약1.96MB다. 전체 디코딩 성공과 moov-before-mdat fast-start를 확인하고 스크롤 장면의 가림 범위를 다시 시각 검증했다. SHA256 `248db34259b95a1876626dc67766c8378d7a18e96252c00569580b983709440f`. 검증 결과는 `build/video-setup-25/final-delivery-verification.json`에 있다. 휴대폰에 만든 임시 촬영본·검증 스크린샷은 PC 사본 확인 후 제거했고, 사용자의 기존 동작검증.mp4는 수정하지 않았다. YouTube 업로드는 사용자가 수행한다.
