# 주차장 도식화 앱 적용

사용자가 기존 시안을 앱에 적용하도록 명시했다. 승인된 시안 PNG를 편집·재생성하지 않고 `assets/images/B1-simplified.png`, `B2-simplified.png`에 복사했다. 회원 지도와 관리자 지도 편집기는 같은 새 자산을 사용한다. `assets/images/B1.png`, `B2.png` 원본과 비교용 시안은 그대로 보존한다.

## 좌표와 기하 구조

기존 지도 영역 비율 B1=2047/1877, B2=3920/2240을 유지하며 `BoxFit.fill`로 같은 영역에 표시한다. 기존 백분율 마커 좌표와 터치 변환, 줌/팬, 관리자 저장 버전은 변경하지 않았다. 서버 운영 데이터·좌표·정책도 변경하지 않았다.

8픽셀 간격 색상 표본의 연결 성분 중심을 정규화해 원본/시안을 비교했다. B1은 청록2·빨강1·노랑2개, B2는 청록9·빨강2·노랑12개로 개수가 일치하며 표본 중심 차이는 대략 캔버스0.5% 이내였다. 이는 표시된 색상 기준점의 간이 비교이며, 모든 실제 충전 마커의 정확도나 벽체·계단·주차면 수 검증을 대체하지 않는다. 현장 대조는 미수행이며 시안의 기하 구조 한계는 유지된다.

## 검증

- 새 자산 사용을 기존 지도 확대/이동 및 관리자 저장 버전 테스트에 추가하고 원래 경로에서 2개 실패를 확인했다.
- 자산 전환 후 최초 테스트는 구형 `build/unit_test_assets`에 새 파일이 없어서 실패했다. 생성 테스트 캐시를 `build/unit_test_assets-before-map-assets`에 보존하고 새로 생성해 재검증했다. 사용자 파일과 원본 이미지는 삭제하지 않았다.
- 지도 확대/이동·관리자 좌표 저장·홈 NFC 가시성 테스트 **4개 통과**, 종료0. `D:/Temp/apt-maps-green.log`.
- `flutter analyze --no-fatal-infos`: **No issues found**, 종료0, 56.3초. `D:/Temp/apt-maps-analyze.log`.
- 원본과 시안/적용본 SHA256을 대조한다. 새 번들은 ZIP 내부 두 도식화 자산이 적용본과 바이트 단위로 일치하는지도 검사한다.

## 배포 파일 구분

최초 `AppBundle/releases/2026-11-16-v1.1.5-22/`는 원본 지도를 사용한 후보이므로 도식화 배포용으로 사용하지 않는다. 도식화 포함 후속 후보는 `AppBundle/releases/2026-11-16-v1.1.5-22-maps/`에 보관한다. 버전은 아직 Play 미제출인1.1.5+22 후보를 유지하며 Console 최고코드 확인이 필요하다. 새 Play 업로드·서버 재배포는 이번 자산 적용에서 수행하지 않는다.

도식화 포함 서명 AAB 빌드·검증을 완료했다. 파일은 `AppBundle/releases/2026-11-16-v1.1.5-22-maps/apt-ev-service-v1.1.5-22-maps.aab`, 87,364,267바이트다. SHA256은 `00a1e14f29afae44639072522422d098b8485463fda7f3931acc9b1544bc43c8`이며 주 에이전트가 별도 재계산했다. 기존 지도 후보 AAB 해시는 `aa32096ce37a6f11970e99d9f9fb7d88a778db29327f8fed64df5c8af0d15992`로 그대로 유지된다.

새 번들 ZIP 내부 B1/B2 도식화 자산이 적용 PNG와 바이트 단위로 같고 원본 두 자산도 보존됨을 확인했다. 실제 manifest의 패키지·버전·min24/target36, 기존 21 업로드 인증서 일치, bundletool 유효성, jarsigner 서명, 64비트 라이브러리10개와 번들의16KB 정렬도 통과했다. metadata·자산 검증·로그·R8 mapping·Dart symbols3개는 새 후보 폴더에 보관한다. 기기 실행·Play 최고 코드·실제 업로드는 미검증/미수행이다.
