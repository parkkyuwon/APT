# Google Play 대상 API 36 대응

사용자가 제공한 원문은 카메라 제재가 아니라 Android 15(API 35) 대상 앱을 Android 16(API 36) 이상으로 갱신해 새 버전을 프로덕션에 게시하라는 요구다. 카메라 조사에서 발견한 사항은 별도 보류하며 이번 변경에 포함하지 않는다.

Blue Ocean PM: 기존 사용자 지정 `gpt-6.1-sol` `/root/pm_review`. 구현과 순차 빌드·검증: root. 변경 하위 그래프 `build → app/platform`, 기존 Flutter Gradle Plugin·AGP 8.11.1·Gradle 8.14·SDK 36 사용. 런타임/UI 동작 변경은 없으며 GUI DR 면제. 새 SDK/플러그인 업그레이드나 외부 서버 변경은 필요 없다.

- targetSdk 35 → 36; 이미 36인 compileSdk 유지.
- 로컬 versionCode 14 → 15; 실제 Play 최고 번호는 확인되지 않았다. 15 이상 이미 사용된 경우 더 큰 번호로 다시 빌드해야 한다.
- `flutter analyze`, 전체 테스트, 운영 설정을 사용하는 로컬 서명 release AAB 빌드를 검증한다. key.properties·키/암호/서비스계정 내용은 출력하지 않는다.
- 최종 AAB의 package/targetSdk/versionCode, 서명 및 native ELF 16KB 정렬을 검사한다.
- Android 16 edge-to-edge·뒤로가기·대화면·사진·BLE·로그인 실기기 검증 범위를 명시한다. 앱 코드에 발견되지 않은 플랫폼 우회 설정을 새로 넣지 않는다.
- Play 업로드/프로덕션 게시를 자동 실행하지 않는다. 게시 완료 전 콘솔 경고가 해소됐다고 주장하지 않는다.

공식 근거: [Play 대상 API 정책](https://support.google.com/googleplay/android-developer/answer/11926878), [Android 16 대상 동작 변경](https://developer.android.com/about/versions/16/behavior-changes-16), [AGP 8.11 지원](https://developer.android.com/build/releases/agp-8-11-0-release-notes).
