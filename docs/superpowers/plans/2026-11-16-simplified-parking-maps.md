# 도식화 주차장 지도 적용

사용자가 기존 B1/B2 시안을 앱에 적용하도록 명시했다. 앞선 원본 유지/미적용 지시는 원본 보존으로 유지하되, 앱 표시 자산은 승인한 도식화 시안으로 변경한다.

- [x] `assets/images/B1-simplified.png`, `B2-simplified.png`에 승인 시안을 그대로 복사한다. 원본 B1.png/B2.png 및 비교용 시안은 보존한다. 이미지 재생성·편집은 하지 않는다.
- [x] 회원 지도와 관리자 편집기 모두 새 자산을 사용한다. 기존 지도 영역 비율과 백분율 좌표·터치·상태 저장 규칙을 유지한다. 두 화면의 새 자산 사용을 기존 확대/좌표 저장 회귀 테스트에서 확인한다.
- [x] Flutter 분석과 지도 관련 테스트를 실행한다. 구조 색인과 검증·인계 기록에 새 적용 상태를 반영한다. 기존 서명22 AAB는 보존하며 새 변경이 포함되지 않았음을 구분한다.
- [x] 도식화 포함 서명22 후보를 별도 maps 폴더에 빌드하고 자산 ZIP 해시·서명·권한·16KB 정렬을 검증한다. 실제 기기·Play 업로드는 미수행이며 적용 기록에 구분한다.

기하 한계: AI 시안은 정밀 도면 추적본이 아니다. 원본/시안의 청록·빨강·노랑 표시 개수와 정규화 중심 위치를 8픽셀 표본으로 비교해 대략0.5% 이내 차이를 관찰했다. 이 검사는 실제 마커별 정확도와 벽체·계단 구조를 보증하지 않는다. 서버 운영 좌표를 자동 이동하거나 운영 주차 정보를 변경하지 않는다.
