# 주차 권한·개인정보·지도 수정

사용자 요구: Google 이름 변경과 무관한 이메일 소유권, 관리자 전체 슬롯 수정,
비공개 전화번호 노출 방지, 평면도 확대 잘림 해소, Computer Use 동작 확인.

1. 기존 사용자 변경을 보존하고 구조 색인과 실제 API 계약을 확인한다.
2. 슬롯 소유권 비교를 이메일 전용 함수로 통일한다. 이름을 식별자로 사용하거나
   소유자 이메일이 없는 기록을 이름으로 추정해 연결하지 않는다.
3. 관리자에게 타인 차량 수정·출차·차단 버튼을 제공한다. 타인 차량 수정은
   원래 ownerEmail/ownerNickname을 보존하며 기존 서버 저장·실패 롤백을 사용한다.
4. 차단 여부와 차량 등록 유무를 구분한다. 타인 비공개 연락처를 입력 컨트롤러에
   넣지 않고, 공개 연락처와 차량번호에는 기존 마스킹을 적용한다.
5. InteractiveViewer를 전체 화면 영역으로 배치하고 내부 이미지·마커를 함께
   변환한다. 이미지 비율과 퍼센트 마커 좌표는 유지한다.
6. 회귀 테스트, 전체 Flutter 테스트, 정적 분석, 격리된 Android fixture를 사용한
   Computer Use 검증을 수행하고 실제 Google/운영 서버 미검증 항목을 기록한다.

백엔드는 D:/vsCodeProg/APT-Prj의 관련 소스만 읽었다. 서버 변경·배포·DB 변경은
이번 작업에 포함하지 않는다. 로컬 관리자 fixture는 운영 권한 검증의 대체가 아니다.
