# 로컬 회원 기능 검증

사용자는 로컬 가상 회원·데이터를 사용하고 검증 뒤 비회원 제한을 복원하는 방식을 선택했다. 기존 화면 디자인과 운영 인증 규칙은 그대로 재사용한다. UI 디자인 변경이 없으므로 별도 시각 디자인 승인은 적용하지 않는다.

영향 구조: app → services → http 및 app → auth → member-ui → parking. 운영 main.dart 대신 debug 전용 진입점을 사용하고 HTTP adapter를 메모리 가상 서버로 교체한다. 알 수 없는 요청과 관리자 요청은 거절하고 실제 서버로 전달하지 않는다. Android 테스트 패키지는 apt.ev.service.localtest로 분리해 운영 앱의 쿠키와 캐시를 공유하지 않는다. release/profile 실행은 차단한다.

가상 승인 회원, 빈/점유/차단 주차 슬롯, 주차 등록·해제, 채팅, 프로필, 이용 내역, 로그아웃을 검증한다. 서버 정책을 인증하거나 실제 Google 로그인, 카메라, BLE, Android 16 호환성을 검증한 것으로 간주하지 않는다. 테스트 완료 후 테스트 앱을 종료하고 일반 앱의 비회원 진입 및 쓰기 차단을 확인한다.

우선 개선 후보: 비동기 화면 종료 안전성, 개인정보 삭제 설명과 서버 정책 일치, 사진 권한·오류 처리, Android 16 실기기 검증. 이번 범위는 테스트 기반 확보와 발견된 재현 가능 결함이다.
