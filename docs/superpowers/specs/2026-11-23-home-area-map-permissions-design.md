# 집 반경 지도와 권한 설정 안내

## 요청과 현재 상태

사용자는 위치를 지정하면 지도에서 확인하고, 부족한 설정은 팝업 안내 후 해당 OS 설정 화면으로 이동하기를 원한다. 현재 HomeAreaSettingsScreen은 GOOGLE_MAPS_ENABLED가 없는 빌드에서 지도를 숨긴다. 현재 배포 설정에는 Maps SDK 키가 없다. 위치·백그라운드·알림 권한 부족은 주로 본문의 문구로 표시한다.

## 제안한 화면

현재 위치 사용 또는 위도·경도 입력 후 실제 도로 지도에 선택 위치 마커와 미터 단위 반경 원을 표시한다. 지도 터치로 중심점을 변경하고 슬라이더로 반경을 바꾼다. 저장된 위치로 다시 열면 같은 지도를 표시한다. 집 좌표는 기존 계정별 기기 보안 저장소에 보존하며 서버 비콘 자료로 보내지 않는다. 지하 B1/B2 도면은 기존 흐름을 유지한다.

Google Maps 키 확보를 기다리는 대신 flutter_map 기반 OpenStreetMap 지도를 권장한다. 기존 Google Maps 유지도 대안이지만 정상 동작하는 SDK 키와 앱 서명 제한 설정이 먼저 필요하다. OpenStreetMap 선택 시 지도 화면에 출처와 온라인 지도 요청 사실을 표시하고, 식별 가능한 User-Agent 및 타일 캐시 정책을 준수한다. 대량 사전 다운로드는 하지 않는다. 네트워크 오류 시 빈 지도를 정상으로 보이지 않고 재시도 안내를 제공한다. 타일 요청으로 지도 영역과 IP가 외부 서비스에 전달될 수 있음을 개인정보처리방침에 반영한다.

## 권한 안내 흐름

감시 켜기 시 앱의 백그라운드 위치 사용 사전 안내와 동의를 먼저 표시한다. 위치 서비스, 정확한 위치, 백그라운드 위치, 알림을 실제 상태에 따라 단계별 확인한다. OS 권한을 앱에서 임의 허용하지 않는다.

권한을 요청할 수 있으면 시스템 권한창을 사용한다. 거부되었거나 OS 설정에서 변경해야 하면 필요한 설정 이름과 이유를 팝업으로 표시한다. 사용자가 팝업의 '설정으로 이동'을 누르면 해당 위치·앱 위치 권한·앱 알림 설정 화면을 연다. 취소는 화면에 남는다. 설정 복귀 시 상태를 다시 확인하고, 사용자가 시작한 설정 과정의 다음 부족한 항목을 안내한다. 팝업 중복 및 설정 화면 반복 실행을 막는다. 필요한 조건을 모두 충족한 경우에만 감시를 시작하고 실패 시 활성 상태로 표시하지 않는다. 계정 변경·로그아웃·관리자 비활성화 시 기존 활성화 취소 규칙을 유지한다.

현재 위치 버튼에서도 위치 서비스 OFF나 위치 권한 영구 거부는 같은 안내 흐름을 사용하되 백그라운드 위치 동의를 강제하지 않는다. 유효하지 않거나 오래된 위치는 저장하지 않는다.

## 영향 범위와 검증

- Flutter: HomeAreaSettingsScreen, 지도 표시 위젯, 권한 설정 안내 상태와 IndoorLocationBridge.
- Android: 기존 indoor_location 채널을 통해 필요한 설정 화면 열기. 기기에서 지원하지 않는 세부 설정 Intent는 앱 상세 설정으로 대체.
- 의존성: OpenStreetMap 선택 시 flutter_map과 좌표 라이브러리. 기존 지하 도면과 BLE 추정 계약은 변경하지 않음.
- 문서: 구조도와 JSON 색인, 기능 검증 기록, 지도 공급자 개인정보 설명.
- 회귀: 위치 변경/반경 원, 저장 재진입, 동의 취소 시 권한 무요청, 부족 권한별 이동, 복귀와 취소, 관리자 비활성화 중 설정 복귀, 권한 부족 시 감시 비활성.
- flutter analyze --no-fatal-infos 및 관련 Flutter 테스트. Android 실기기에서 지도 로딩과 설정 이동/복귀를 확인. 실제 지하 알림은 별도 현장 검증으로 구분.

## 검토 상태

사용자가 OpenStreetMap 방식을 선택하여 설계를 승인했다. 구현과 검증은 계획 및 검증 기록을 따른다. 기존 사용자 변경을 포함하는 커밋은 만들지 않는다.
